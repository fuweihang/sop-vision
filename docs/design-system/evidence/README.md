# Evidence

本目录只登记设计推导所使用的原始证据。截图和 Playwright 输出目前保留在仓库根目录，`manifest.json` 使用相对路径引用它们，避免无意义复制二进制文件。

证据分级：

- `observed`：来自截图、DOM 或计算样式的直接结果。
- `normalized`：为形成一致设计系统而进行的取整、命名或合并。
- `inferred`：从 CSS 变量或单一视口推导，必须在真实页面中验证。

证据可能包含登录后界面的团队名称、用户名或资源状态。不得将其上传到公开文档、模型训练集或第三方服务。清单不得记录 Cookie、Token、密码、请求头或其他认证信息。
