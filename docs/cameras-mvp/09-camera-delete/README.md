# 09｜删除 Camera

> 前置：[Cameras 基础契约](../01-foundation/README.md)、[Camera 详情](../04-camera-detail/README.md)  
> 交付：`DELETE /cameras/{camera_id}`、危险操作确认、聚合删除和缓存清理

## 1. 完成目标

用户可以从 Camera 详情页二次确认后删除 Camera。数据库在一个事务中删除 Camera 及其全部 CameraSource；除资源存在性外没有其他业务前置条件，也不引入异步清理工作流。

浏览器预览会话和短期状态不会阻止删除。

## 2. 范围

### 后端

- 校验 Camera 存在性。
- 在一个事务删除 Camera 聚合。
- 提交后清除内存状态并尽力释放播放映射。
- 返回稳定 204、404 和依赖无关语义。

### 前端

- 详情页危险操作区和二次确认对话框。
- 确认、提交中、失败和成功返回列表。
- 关闭当前播放器并清理相关 Query 缓存。

### 不属于本模块

- 跨业务查询、计数、删除保护或级联处理。
- 软删除、恢复站、批量删除或删除审批。
- 可靠异步清理及其运维管理页面。

## 3. API

```http
DELETE /api/v1/cameras/6f9619ff-8b86-4e4f-9f68-bb3f8f6f4f21
```

成功：

```http
HTTP/1.1 204 No Content
```

成功响应没有响应体。

## 4. 删除语义

- Camera 和全部所属 CameraSource 在同一个数据库事务中删除。
- 删除不检查 Camera 或 Source 是否被其他数据使用。
- 删除不因 Source 为 `ONLINE`、存在浏览器预览或 MediaMTX 映射而被阻止。
- 数据库提交成功即向客户端返回 `204`。
- 提交后对每个 Source 调用 `release_source`。
- MediaMTX 释放失败不回滚数据库删除，也不把 `204` 改为依赖错误。
- MVP 不保存可靠清理事件；极端进程崩溃可能留下可重建的媒体映射，后续运维或服务重启可处理，不影响 Camera 已删除的业务事实。
- 对已不存在 Camera 的 DELETE 返回 `404 CAMERA_NOT_FOUND`。

## 5. 后端处理流程

1. 读取并锁定 Camera，同时记录所属 `source_id` 列表。
2. 不存在返回 `404 CAMERA_NOT_FOUND`。
3. 在同一事务显式删除全部 CameraSource，再删除 Camera；任一步骤失败则整体回滚。
4. 提交成功后尽力释放播放映射。
5. 返回 `204`。

在数据库提交前不得调用不可回滚的外部释放操作。数据库删除失败时必须保留完整聚合。

## 6. 前端交互

- 删除入口只放在 Camera 详情页危险操作区，不放在卡片快捷菜单。
- 点击后弹出确认框，显示 Camera 名称和 Source 数量，并明确说明不可恢复。
- 用户必须点击明确的“删除摄像头”按钮；取消、关闭或 Escape 不执行删除。
- 提交期间禁用确认按钮和对话框关闭，避免重复请求。
- 发请求前先正常停止当前页面播放器。
- 成功后移除当前 `camera`、所属 Source 的 `playback`，失效所有 `cameras`，再跳转 `/cameras`。
- 其他失败保留详情页面并允许重试。

## 7. 错误与恢复

| 场景 | 响应/前端行为 |
| --- | --- |
| Camera 不存在 | `404 CAMERA_NOT_FOUND`，返回列表并刷新 |
| 数据库不可用 | `503 DATABASE_UNAVAILABLE`，保留详情 |
| 提交后播放映射释放失败 | 仍返回 `204`，记录告警和指标 |

本模块不返回业务占用冲突或删除处理中状态。

## 8. 可观测性

- 成功日志包含 `trace_id/camera_id/source_count`，不包含凭据或 RTSP URL。
- 记录删除成功、数据库失败和播放释放失败数量。
- 播放释放失败日志使用 `source_id` 和稳定 error code，不记录下游敏感响应体。
- 后提交清理不得无限等待；总等待上限为 2 秒，超时后结束请求并记录告警。

## 9. Fixture

至少提供：

- 单 Source 和多 Source Camera 删除。
- 正在预览和状态为 ONLINE 的 Camera 删除。
- Camera 不存在和数据库失败。
- 播放释放超时和资源已不存在。

## 10. 独立验收

1. 删除成功后 Camera 和全部 Source 均不存在，返回 `204`。
2. 无论 Source 状态或预览是否活跃，删除都能正常提交。
3. 数据库事务失败时 Camera 和全部 Source 仍完整存在。
4. MediaMTX 映射释放失败时数据库删除仍成功并返回 `204`。
5. 前端成功后关闭播放器、清理缓存并返回列表。
6. 日志和错误体不包含用户名、密码或完整 RTSP URL。

## 11. Definition of Done

- DELETE 路由、事务删除和提交后尽力清理已实现。
- 危险操作区、确认对话框、缓存清理和导航已实现。
- 数据库原子性、依赖故障和播放器关闭均有自动化测试。
- 文档明确记录直接删除语义和无可靠异步清理的 MVP 限制。
