# 技术决策记录

这里保存跨模块、长期有效且修改成本较高的决定，例如数据所有权、服务边界、公共安全策略或协议
选择。模块内部规则直接写在 `modules/<module>/`，单次实现步骤写在 `plans/`。

新增文件使用 `NNNN-<topic>.md`，编号递增。正文至少包含：

1. 背景：什么问题迫使我们做决定。
2. 决定：最终采用什么，以及明确不采用什么。
3. 影响：对代码、数据、部署、兼容性和后续开发的影响。
4. 调整条件：出现什么事实时需要重新评估。

决策记录只解释原因；当前可操作规则仍由对应模块文档负责，并从决策记录链接过去。
