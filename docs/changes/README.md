# 变更记录

本目录记录已经交付且会影响使用、集成、部署或后续开发的变化。它回答“这次交付改变了什么”，
不重复模块文档中的全部当前规则。

## 文件规则

- 文件名使用 `YYYY-MM-DD-<topic>.md`；同一天同主题只写一份。
- 标题说明交付能力，正文包含“变化、影响、验证、相关长期文档”。
- API、数据库、配置、兼容性或安全没有变化时明确写“无”。
- 不记录逐文件 diff、提交列表、测试通过数量和开发过程。
- 修复原记录中的事实错误可以直接修改；后续行为再次变化时新增记录，不覆盖历史影响。
