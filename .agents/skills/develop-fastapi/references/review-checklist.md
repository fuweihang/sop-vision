# FastAPI 开发审查清单

## 范围与兼容性

- [ ] 已阅读适用的仓库规则、架构和功能契约。
- [ ] 已检查 `git status` 并保留用户改动。
- [ ] 已找到应用入口、路由注册、调用方、测试和迁移。
- [ ] 未修改无关模块或未经允许改变协议。
- [ ] 使用的是项目真实版本与当前官方文档。

## 接口协议

- [ ] 方法、路径、`operation_id` 和成功状态码正确。
- [ ] Path、Query、Header、Body 类型与边界明确。
- [ ] Create、Update/Patch、Detail 和 List Schema 语义清晰。
- [ ] PATCH 能区分未提供与显式 `null`。
- [ ] `204` 没有响应体。
- [ ] 响应头、缓存和内容类型满足契约。
- [ ] 错误状态、稳定错误码和 OpenAPI 声明一致。
- [ ] 列表有数量上限、分页和稳定排序。
- [ ] 调用方、OpenAPI、SDK 或前端类型已同步。

## 分层与依赖

- [ ] Router 中没有 SQL、业务编排和事务提交。
- [ ] Service 不依赖 FastAPI 或抛 `HTTPException`。
- [ ] Repository 不依赖 API Schema 且没有 `commit()`。
- [ ] API Schema、应用 DTO 与 ORM Record 没有混用。
- [ ] 外部 SDK 被 Adapter 或最小 Port 隔离。
- [ ] 具体实现集中在依赖装配边界。
- [ ] 没有循环依赖、万能抽象或无意义层级。

## 鉴权与安全

- [ ] Service 使用稳定、最小的调用者模型。
- [ ] 所有权、租户和软删除条件进入查询。
- [ ] `403/404` 防枚举策略与项目一致。
- [ ] 响应只包含调用方需要的字段。
- [ ] 日志和错误不包含密码、Token、连接串或完整凭据 URL。
- [ ] 必须返回的敏感字段具有正确鉴权、响应头和缓存保护。
- [ ] 未暴露 SQL、堆栈或第三方原始敏感响应。

## 事务与并发

- [ ] 一个用例有一个明确事务边界。
- [ ] 同一用例的 Repository 共享 Session/UoW。
- [ ] 异常和提交失败路径正确回滚。
- [ ] 外部调用不会无意中长时间持有事务。
- [ ] 唯一性由数据库约束或等价机制保证。
- [ ] 状态写入使用原子条件更新、锁或版本控制。
- [ ] 未使用“先查再写”假装保证并发正确。
- [ ] 未使用进程内锁承担跨 worker/实例一致性。
- [ ] 数据库提交后的外部副作用有清晰失败语义。
- [ ] 幂等和安全重试规则明确。

## ORM、数据库与迁移

- [ ] 主键、nullable、长度、默认值和时区明确。
- [ ] 外键、唯一/check 约束与索引匹配查询。
- [ ] ORM Record 没有直接作为 API Response。
- [ ] ORM 变化有正式迁移。
- [ ] 自动生成迁移已经人工审查。
- [ ] 已处理旧数据回填和约束建立顺序。
- [ ] 空数据库和已有版本升级路径已验证。
- [ ] 没有用应用启动 DDL 替代迁移。

## 外部服务与生命周期

- [ ] 客户端复用范围与关闭时机正确。
- [ ] 请求状态未存入全局单例。
- [ ] 超时、有限重试和异常转换明确。
- [ ] 降级行为来自业务契约且可观测。
- [ ] 后台任务可取消、可关闭且异常不会静默。
- [ ] 多 worker 或多实例语义明确。

## 测试

- [ ] 成功路径和输入校验已覆盖。
- [ ] 相关认证、权限、404、冲突和依赖故障已覆盖。
- [ ] 事务提交与回滚已覆盖。
- [ ] 关键 Repository 语义使用目标数据库验证。
- [ ] 并发、重复请求或幂等行为已覆盖。
- [ ] 响应字段、响应头和错误协议已覆盖。
- [ ] 外部 Adapter 的超时、无效响应和降级已覆盖。
- [ ] 敏感信息不泄露已回归。
- [ ] 数据库变化的迁移已测试。

## 最终验证

- [ ] 已运行仓库规定的格式化和静态检查。
- [ ] 已运行目标测试和必要回归测试。
- [ ] 已检查 OpenAPI 或调用方契约。
- [ ] `git diff --check` 已通过。
- [ ] 已审查完整 diff 和 `git status --short`。
- [ ] 最终报告准确区分已通过、失败和未执行项。
